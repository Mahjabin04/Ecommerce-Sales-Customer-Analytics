# E-Commerce Sales & Customer Analytics

## Project Overview

This project is an end-to-end e-commerce analytics project based on the Brazilian E-Commerce Public Dataset by Olist.

The objective is to analyze sales performance, customer behavior, product performance, delivery operations, and customer satisfaction using Excel, MySQL, SQL, and Power BI.

The project follows a structured analytics workflow:

1. Data understanding and profiling
2. Data quality assessment
3. Relational database setup
4. SQL-based analysis
5. Customer and sales analytics
6. Advanced analysis
7. Power BI dashboard development
8. Business insights and recommendations

## Business Questions

The project aims to answer questions such as:

- How has revenue changed over time?
- Which product categories generate the most revenue?
- Which geographic regions generate the most sales?
- Who are the most valuable customers?
- What percentage of customers make repeat purchases?
- Which product categories perform best and worst?
- How efficiently are orders delivered?
- How frequently are deliveries late?
- Does delivery performance affect customer review scores?
- How concentrated is revenue across customers and product categories?

## Dataset

This project uses the Brazilian E-Commerce Public Dataset by Olist.

The dataset contains approximately 100,000 orders and includes customer, order, product, payment, seller, delivery, geolocation, and review information.

### Dataset Source

Brazilian E-Commerce Public Dataset by Olist

https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce

The original raw CSV files are not stored in this repository. They can be downloaded directly from the Kaggle source above.
