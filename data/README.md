# Dataset

## Source

This project uses the Brazilian E-Commerce Public Dataset by Olist.

Dataset source:

https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce

The dataset contains anonymized e-commerce orders and includes information related to customers, orders, products, sellers, payments, delivery, reviews, and geographic locations.

## Files

The original dataset contains the following CSV files:

- olist_customers_dataset.csv
- olist_geolocation_dataset.csv
- olist_order_items_dataset.csv
- olist_order_payments_dataset.csv
- olist_order_reviews_dataset.csv
- olist_orders_dataset.csv
- olist_products_dataset.csv
- olist_sellers_dataset.csv
- product_category_name_translation.csv

## Raw Data

The original raw CSV files are not stored in this GitHub repository.

To reproduce the project:

1. Download the dataset from Kaggle.
2. Extract the CSV files.
3. Store them locally in a `raw_data` folder.
4. Import the datasets into MySQL.

## Data Handling

The raw data is kept unchanged locally.

Any transformations, cleaning rules, and analytical decisions used in this project will be documented separately.
